# 소비자 GPU 환경에서의 대규모 VLA 모델 메모리 최적화 추론 연구

## 연구 배경

자율주행용 Vision-Language-Action(VLA) 모델의 규모가 급격히 증가하면서, 소비자급 GPU에서의 추론이 현실적으로 불가능해지는 VRAM 벽(VRAM Wall) 문제가 대두되고 있다. 대표적으로 NVIDIA Alpamayo-R1-10B은 FP16 기준 22.16 GB의 파라미터 메모리를 요구하나, RTX 3080 Ti와 같은 소비자 GPU는 12 GB VRAM만 제공한다. 현재 유일한 대안인 CUDA Unified Memory의 페이지 폴트 기반 자동 스와핑은 273.79초의 추론 시간을 발생시키며, 이는 이론적 최적(~5초) 대비 55배 느린 수치로, 추론 시간의 98%가 스와핑 오버헤드에 해당한다.

기존 오프로딩 시스템(FlexGen, DeepSpeed, vLLM 등)은 주로 다중 GPU 환경 또는 LLM 배치 서빙에 특화되어 있으며, 소비자 GPU에서의 단일 추론 최적화, 특히 Vision + Language + Action 이기종 모듈 구조에 대한 체계적 연구는 부재한 상황이다.

## 연구 목표

본 연구는 **모델 정확도를 완전히 보존**하면서(양자화·가지치기 배제), 12 GB VRAM 소비자 GPU에서 FP16 Alpamayo-R1-10B의 추론 시간을 **Baseline(273.79초) 대비 10배 이상 개선**(25초 이하)하는 시스템/메모리 레벨 최적화 기법을 개발하는 것을 목표로 한다.

## 연구 방법

핵심 기법은 **Zero-D2H On-Demand Layering**이다. GPU 메모리에 적재 불가능한 레이어를 CPU에 원본으로 보존하고, 추론 시 필요한 레이어만 H2D(Host-to-Device) 전송하여 실행한 뒤, 기존 시스템과 달리 D2H(Device-to-Host) copy 없이 GPU 메모리를 즉시 해제한다. 예비 실험에서 D2H 제거만으로 116.51초 → 43.38초(2.68배 개선)를 달성하여, 파라미터 추론에서의 D2H 불필요성을 실증하였다.

이를 기반으로 세 가지 추가 최적화를 적용한다. 첫째, **Pinned Memory 최적 청크 전송**으로 H2D 대역폭을 7.77 GB/s에서 12.4 GB/s로 향상시킨다. 둘째, **2-Stream 비동기 파이프라인**(Compute + H2D Prefetch)으로 연산과 전송을 시간적으로 오버랩한다. 셋째, Alpamayo의 이기종 3-모듈 구조(Vision 1.15 GB / VLM 15.17 GB / Expert 4.56 GB)에 대해 **적응형 메모리 스케줄링**을 적용하여, 작은 모듈(Vision, Expert)은 GPU에 상주시키고 VLM 레이어만 on-demand로 회전시킨다.

## 예비 실험 결과

8단계 예비 실험을 통해 기술적 타당성을 확인하였다. Baseline(273.79초)에서 출발하여, On-Demand Layering(116.51초, 2.35x) → D2H 제거(43.38초, 6.31x) → 비동기 Prefetch(**38.45초, 7.12x**)까지 단계적 개선을 달성하였다. 또한 PCIe Gen3(8.5 GB/s)과 VRAM 대역폭(912 GB/s)의 107배 격차로 인해, 파이프라이닝만으로는 전송을 연산에 완전 은닉하는 것이 구조적으로 불가능하다는 한계도 규명하였다.

## 기대 성과

본 연구의 학술적 기여는 다음과 같다. (1) 파라미터 추론에서 D2H copy가 불필요함을 정량적으로 입증한 Zero-D2H 오프로딩 기법 제안, (2) VLA 이기종 모듈 구조에 대한 적응형 메모리 스케줄링 기법 최초 제시, (3) 12 GB VRAM + PCIe Gen3 환경에서의 구조적 성능 한계 규명 및 실용적 최적화 달성. 최종적으로 소비자 GPU에서 대규모 VLA 모델의 실용적 추론 가능성을 입증하고, 에지 디바이스 및 로보틱스 분야에서의 온디바이스 추론 활용 경로를 제시하고자 한다.
